# Общие модули

Скопируйте каталоги модулей в расширение или основную конфигурацию и создайте метаданные из `docs/metadata.md`.

Модули используют управляемые блокировки, серверный контекст и нейтральный транспортный контракт. Имена прикладных
объектов и конкретный Kafka-драйвер намеренно не заданы.
