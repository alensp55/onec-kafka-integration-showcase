# Интеграция 1С с Apache Kafka

Нейтральный каркас двустороннего обмена между 1С и Kafka.

В репозитории:

- входящая и исходящая очереди;
- идемпотентная запись сообщений;
- producer и consumer через сменный транспортный адаптер;
- ручное подтверждение offset после сохранения сообщения;
- повторные попытки с ограниченной экспоненциальной задержкой;
- три независимых фоновых задания;
- безопасный журнал без тел сообщений и реквизитов подключения;
- исполняемая модель поведения и тесты.

Рабочая обработка, конфигурация, внешняя компонента и данные проекта не публикуются. Код написан заново и использует
только обобщённые контракты интеграции.

## Подключение

1. Создайте метаданные по [описанию](docs/metadata.md).
2. Добавьте общие модули из `extension/CommonModules`.
3. Реализуйте [транспортный адаптер](docs/adapter-contract.md) для выбранного Kafka-драйвера.
4. Передайте фабрику транспорта в процедуры фоновых заданий.
5. Храните пароли и сертификаты вне исходного кода.

## Проверка
